# Speech-to-Text Pad

A simple, fast, and privacy-focused web application that converts your speech into text in real-time. Save your thoughts, notes, and transcriptions directly in your browser.

## Features

*   **Real-time Transcription**: Converts your speech to text as you speak.
*   **Save Notes**: Save your transcribed text as notes for later reference.
*   **Local Storage**: All your notes are saved in your browser's local storage. No data is sent to any server.
*   **Theme Toggle**: Switch between light and dark themes for your comfort.
*   **Copy to Clipboard**: Easily copy your transcriptions to the clipboard.
*   **Clear Draft/Notes**: Options to clear the current draft or all saved notes.

## How to Use

1.  Open `index.html` in your web browser (preferably Chrome or Edge for the best experience with the Web Speech API).
2.  Click the "Start" button to begin transcription.
3.  Allow the browser to access your microphone.
4.  Start speaking, and your words will appear in the text area.
5.  Click "Stop" to pause the transcription.
6.  Click "Save" to store the current transcription as a note.

## Technologies Used

*   HTML5
*   CSS3
*   JavaScript
*   Web Speech API
